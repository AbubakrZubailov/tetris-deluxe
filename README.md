# Tetris Deluxe — версия для компьютера

Полноценная обновлённая игра Tetris для **Python 3.10+ и Pygame 2.5+**.
Работает локально, без сервера и интернета. Оригинальные картинки и звуки не нужны: интерфейс, частицы, звуковые эффекты и мелодия создаются программно.

## Скачать игру для Windows

На странице [последнего релиза](https://github.com/AbubakrZubailov/tetris-deluxe/releases/latest) скачайте TetrisDeluxe.exe и откройте файл. Сборка предназначена для 64-разрядной Windows и включает Python и Pygame. Настройки и рекорды хранятся в папке `%LOCALAPPDATA%\Tetris Deluxe`.

## Запуск из исходников в Windows

1. Установите Python 3 с https://www.python.org/downloads/ (при установке отметьте **Add Python to PATH**; рекомендована версия Python с доступным pygame).
2. Скачайте или клонируйте репозиторий в обычную папку, например `C:\Games\Tetris_Deluxe`.
3. Запустите **`install_windows.bat`** один раз для установки Pygame.
4. Откройте **`play_windows.bat`** для запуска игры.

Если `py -3` не распознаётся, откройте командную строку в папке игры и выполните:

```bat
python -m pip install -r requirements.txt
python tetris.py
```

## Linux / macOS

```bash
python3 -m pip install -r requirements.txt
./play_linux_mac.sh
```

На Linux при запуске через SSH нужен графический сеанс. Если звукового устройства нет, игра запускается без звука.

## Режимы

- **Classic** — обычный Tetris с очками и повышением уровня.
- **Sprint 40** — очистить 40 линий на время; сохраняется лучший результат и лучшее время.
- **Ultra 2:00** — набрать максимум очков за две минуты.
- **Survival** — скорость падения дополнительно растёт каждые 22 секунды.

Размер поля **12 × 24** (как в исходном Tetris). В игре есть 7-bag распределение фигур, подсказка Ghost, предварительный показ трёх фигур, бонусы за комбо и последовательные Tetris, вращение у стен.

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Перемещение фигуры |
| ↑ | Поворот |
| ↓ | Ускоренное падение |
| Space | Мгновенное падение |
| P / Esc | Пауза |
| R | Новая партия в том же режиме |

В главном меню и на экране выбора режима работают **↑ / ↓ / Enter**. В Settings — **Tab** для переключения вкладок, **↑ / ↓** для выбора параметра, **← / →** для изменения и **Enter** для назначения клавиши. Управление полностью переназначается во вкладке Controls; при конфликте клавиши меняются местами. Во всём интерфейсе можно пользоваться мышью.

Во время паузы доступны **Resume**, **Settings**, **Restart**, **Main menu**. Оставшаяся незавершённой партия учитывается в статистике как завершённая при выходе в меню.

## Настройки

- Оформление: Neon / Classic / Minimal.
- Сетка, Ghost, частицы и свечение, полноэкранный режим.
- Сложность easy / normal / hard и множитель скорости 0.5×–2.0×.
- Отдельная громкость музыки и звуковых эффектов.
- Переназначение клавиш.

Настройки применяются сразу и сохраняются автоматически.

## Достижения и награды

Десять достижений: первая партия, 1 000/10 000 очков, первый Tetris, серия комбо, 100 линий, уровень 10, 10 партий, Sprint и Ultra. За каждое открытое достижение игрок получает **100 звёзд** — отображаются на странице Achievements. Звёзды пока являются коллекционной наградой, их нельзя тратить.

## Сохранение рекордов и прогресса

В папке игры создаются:

- `tetris_settings.json` — оформление, скорость, управление и другие настройки;
- `tetris_deluxe_data.json` — рекорды по четырём режимам, статистика, достижения.

Если у вас уже есть **`highscore.json`** от первоначального Tetris, **скопируйте его без изменений в папку Tetris_Deluxe** рядом с `tetris.py`. При запуске рекорд автоматически подхватится в Classic (если он выше нового). Старая игра и оригинальный `highscore.json` **не изменяются и не перезаписываются**.

## Проверка

```bash
python -m unittest discover -s tests -v
python -m py_compile tetris.py tetris_core.py tetris_audio.py tetris_ui_logic.py
```

Тесты проверяют игровую механику, миграцию рекорда, хранение настроек, навигацию, игровые экраны и результаты. Для автоматической проверки интерфейса используется имитация Pygame, поэтому на машине с графической средой рекомендуется один раз проверить реальный запуск и воспроизведение звука.

## Структура

- `tetris.py` — графический интерфейс, анимации, управление, полноэкранный режим.
- `tetris_core.py` — игровая логика, рекорды, достижения и сохранения.
- `tetris_ui_logic.py` — настройки и переназначение клавиш.
- `tetris_audio.py` — синтезированная музыка и звуковые эффекты.
- `tests/` — автоматические тесты.
